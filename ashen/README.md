# ASHEN

Стрит-вир магазин: иммерсивная кибер-платформа и комьюнити-хаб.
Дропы = события. Покупка = доступ.

Тёмная кибер-эстетика + тихий эстетский люкс. Монохром плюс один фиолетовый акцент.

---

## Запуск

Сайт — статические страницы на ES-модулях плюс сервер платежей.
**Никаких зависимостей**: только стандартная библиотека Node 20+.

```bash
cd "проект 1"
node server/server.mjs
```

Открыть: **http://127.0.0.1:4173/index.html**

Из коробки работает **демо-режим**: платежи эмулируются, деньги не двигаются,
но весь цикл проходится целиком — корзина → платёж → оплата → ACCESS GRANTED →
заказ в кабинете.

Чтобы принимать настоящие деньги:

```bash
cp .env.example .env      # заполнить ключи ЮKassa и реквизиты
# ASHEN_MODE=live
node server/server.mjs
```

Подробно: **[docs/payments.md](docs/payments.md)** — вебхук, чеки 54-ФЗ,
возвраты, рассрочка, чек-лист перед первым дропом.

## Оплата через ЮKassa

Секретный ключ живёт **только на сервере**. Браузер присылает `id` товара,
размер и количество — цены и суммы назначает сервер. Данные карты мы не видим:
их вводит покупатель на стороне ЮKassa, полей карты в нашей форме нет вообще.

```
браузер → POST /api/payments → сервер → POST /v3/payments → ЮKassa
                                        ← confirmation_url
браузер → на форму оплаты ЮKassa
                                        ← вебхук payment.succeeded
                                        → GET /v3/payments/{id}  ← сверяем,
                                        → заказ: paid                 телу не верим
браузер → GET .../sync → ACCESS GRANTED
```

Что уже работает:

- **Создание платежа** с обязательным `Idempotence-Key`: повторный запрос
  возвращает тот же заказ, а не создаёт второй.
- **Вебхук** с проверкой HMAC-подписи за постоянное время. Тело уведомления
  источником истины не считается — платёж всегда перезапрашивается через API.
- **Чеки 54-ФЗ**: позиции, НДС, СНО, доставка отдельной позицией как услуга.
  Сумма чека сходится с суммой платежа до копейки при любой скидке.
- **Возвраты и отмены** под токеном администратора, частичные и полные.
- **Рассрочка** отдельным потоком, со своими ограничениями.
- **Валидация на сервере**: распроданный размер, чужой размер, подмена цены,
  количество больше остатка — всё отсекается.

## Что работает по-настоящему

- **Таймер до дропа** — ближайшая пятница, 20:00, живой отсчёт.
- **Очередь** — позиция, класс доступа, раннее окно. Хранится на сервере.
- **Рефералка** — ссылка с кодом, +400 позиций за друга, инвайт за каждые 3.
- **Корзина** — между перезагрузками, живёт в браузере.
- **Заказы** — на сервере. Кабинет спрашивает статус у сервера, а сервер — у ЮKassa.
- **Скидка «своих»** — 5%, считается на сервере по реестру очереди.
- **Каталог** — восемь дропов с реальными остатками по размерам.
- **Чат** — сообщения сохраняются, собеседники отвечают.

## Пересборка и проверка

```bash
node tools/gen-assets.mjs     # перегенерировать всю графику
node tools/build-pages.mjs    # пересобрать страницы и server/catalog.json
node tools/build-legal.mjs    # пересобрать документы с реквизитами из .env
```

Тесты (Playwright уже установлен глобально; если ссылки нет —
`ln -sfn "$(npm root -g)/playwright" .testdeps/playwright`):

```bash
node --test test/payments.test.mjs test/flow.test.mjs   # 86 проверок, ключи не нужны
node tools/verify.mjs          # 13 страниц + путь покупателя целиком
node tools/audit-layout.mjs    # вёрстка: 4 разрешения × 13 страниц
node tools/check-brief.mjs     # сверка с ТЗ: 47 пунктов
```

Скриншоты проверок складываются в `.verify/`.

## Tone of voice

На «ты». Коротко. Сленг и ирония без перегиба. Техно-вайб.

- «Дроп 07. Пятница. 20:00. Не проспи.»
- «Тут пусто. Как в твоём вишлисте.»
- «Встань в очередь. Свои заходят первыми.»
- «ASHEN. Тише. Свет уже погас.»

Никаких «Успей купить!», капса и эмодзи-россыпи. Подробнее — в `docs/social-content.md`.
