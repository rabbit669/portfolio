# Демо №3. ИИ-ассистент по базе знаний

Ассистент, который отвечает на вопросы клиентов **только по документам компании** и всегда показывает источники. Это то, что заказывают в 2025–2026 чаще всего: «хочу нейросеть, которая знает наши условия и не выдумывает».

## Зачем это бизнесу

- Поддержка отвечает на 60–80 % одних и тех же вопросов: доставка, оплата, возврат, гарантия.
- Обычная нейросеть на такие вопросы **выдумывает** цифры и сроки — это прямой убыток и жалобы.
- Этот ассистент физически не может ответить мимо базы: если в документах ответа нет, он честно говорит «уточните у оператора».

## Как устроено

```
вопрос клиента
   → поиск релевантных фрагментов в базе знаний (BM25, офлайн)
   → языковая модель формулирует ответ строго по найденным фрагментам
   → ответ + список источников
```

Поиск реализован вручную, без внешних библиотек и без интернета: разбивка документов на фрагменты, нормализация русских словоформ («доставка/доставки/доставку» — одно слово), ранжирование BM25. Это значит, что ассистент **не зависит от платных сервисов** и отвечает мгновенно, а модель подключается только для формулировки.

## Запуск

```bash
cd "/Users/macmaksim/Desktop/проекты/проект 3/портфолио/03_ии_ассистент"

# офлайн-режим, без ключей и интернета — работает всегда
../../.venv/bin/python assistant.py --ask "сколько стоит доставка в Казань"
../../.venv/bin/python assistant.py --demo --no-llm

# с языковой моделью (любой OpenAI-совместимый API: OpenAI, OpenRouter, локальный сервер)
export LLM_API_KEY="ваш_ключ"
export LLM_MODEL="gpt-4o-mini"
../../.venv/bin/python assistant.py --interactive

# сохранить результаты всех демо-вопросов
../../.venv/bin/python assistant.py --demo --json результат/ответы.json
```

Свои документы кладутся в папку `docs/` — обычные `.md`, `.txt` или `.csv`. Переиндексация происходит при каждом запуске, ничего обучать не нужно.

## Что показывает заказчику

| Возможность | Как показано |
|---|---|
| Ответы по документам, без выдумок | Промпт запрещает выходить за пределы найденных фрагментов; при отсутствии ответа ассистент отправляет к оператору |
| Прозрачность | К каждому ответу приложены источники с оценкой релевантности |
| Работа офлайн | Демо работает без ключей и без интернета — заказчик видит результат сразу |
| Независимость от вендора | Поддерживается любой OpenAI-совместимый API, включая локальные модели |
| Русский язык | Нормализация словоформ учитывает русскую морфологию |
| Простота внедрения | База знаний — обычные текстовые файлы, которые ведёт сам заказчик |

## Пример ответа

```
ВОПРОС: Сколько стоит доставка в другой город?

Доставка в другие города России — от 450 ₽, срок от 2 до 7 рабочих дней в зависимости от региона.
В Казань, Екатеринбург и Новосибирск доставка обычно занимает 3 рабочих дня и стоит 550 ₽.
Доставка по Москве и Санкт-Петербургу — 350 ₽, при заказе от 5 000 ₽ бесплатно.

Источники:
  • доставка · фрагмент 1 — релевантность 4.072
  • частые вопросы · фрагмент 2 — релевантность 2.649
```

## Направления внедрения, которые продаются отдельно

1. **Внутренний ассистент для сотрудников** — регламенты, инструкции, скрипты продаж вместо поиска по папкам.
2. **Отвечает на отзывы** на маркетплейсах и картах в тональности бренда.
3. **Первая линия поддержки в Telegram** — связка с демо №2.
4. **Ассистент отдела продаж** — мгновенные ответы по прайсу и условиям, подготовка КП.
5. **Генерация карточек товаров** — описания и характеристики по фото и таблице поставщика.

## Структура

```
03_ии_ассистент/
├── assistant.py   — CLI: один вопрос, диалог, демо-прогон, экспорт в JSON
├── retrieval.py   — фрагментация документов, нормализация, индекс BM25
├── llm.py         — подключение языковой модели + офлайн-режим
├── docs/          — база знаний: доставка, оплата, возврат, гарантия, частые вопросы
└── результат/     — демо-ответы и экспорты
```
