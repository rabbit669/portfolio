# Демо №1. Парсер каталога → Excel + HTML-отчёт

## Что это

Рабочий скрипт, который обходит каталог интернет-магазина с пагинацией **по всем категориям**, собирает структурированные данные и на выходе отдаёт:

- **Excel-файл** с 5 листами: все товары с автофильтром, сводка по категориям со встроенным графиком Excel, распределение по рейтингу, топ-15 дорогих и дешёвых, лист с метаданными сбора;
- **HTML-отчёт** с диаграммами (гистограмма цен, средние цены по категориям, распределение по рейтингу) — самодостаточный файл, открывается в любом браузере без интернета;
- **CSV и JSON** с сырыми данными — чтобы заказчик мог забрать данные в свою систему.

## Что демонстрирует заказчику

| Возможность | Как показано в проекте |
|---|---|
| Обход пагинации | Скрипт сам находит кнопку «следующая страница» и идёт до конца категории |
| Работа с категориями | Список категорий определяется автоматически из структуры сайта, а не хардкодом |
| Устойчивость к сбоям | Повторы запросов при ошибках, паузы между запросами, обработка отсутствующих полей |
| Чистота данных | Цены приводятся к числу, рейтинг из CSS-классов в число, наличие — в булево + количество |
| Готовые отчёты | Не «таблица в консоли», а Excel и HTML, которые можно сразу отдать руководителю |
| Соблюдение приличий | Задержки между запросами, понятный User-Agent, отсутствие нагрузки на сайт |

## Запуск

```bash
cd "/Users/macmaksim/Desktop/проекты/проект 3/портфолио/01_парсер_в_excel"

# полный обход (50 категорий, ~1000 товаров)
../../.venv/bin/python run.py --categories 50 --delay 0.15

# быстрая демонстрация
../../.venv/bin/python run.py --categories 5
```

Результаты складываются в папку `результат/`, сырые данные — в `data/`.

## Структура

```
01_парсер_в_excel/
├── parser.py     — обход сайта: категории, пагинация, разбор карточек, повторы при ошибках
├── report.py     — Excel (5 листов + график) и HTML-отчёт с диаграммами
├── run.py        — полный цикл одной командой
├── data/         — сырые данные: raw.json, books.csv
└── результат/    — каталог_товаров.xlsx, отчёт.html, графики PNG
```

## Технические детали

- Python 3.9, библиотеки: `requests`, `beautifulsoup4`, `lxml`, `openpyxl`, `pandas`, `matplotlib`.
- Источник данных для демонстрации — открытый тренировочный каталог `books.toscrape.com`, специально предназначенный для отработки парсинга (1000 товаров, 50 категорий, реальная пагинация).
- Скрипт легко перенастраивается на любой другой сайт: меняются только селекторы разбора карточки и логика пагинации.

## Что заказчик получает при заказе похожей задачи

1. Рабочий скрипт под его сайт (не демо), с настройками в отдельном конфиге.
2. Выгрузку в удобном формате: Excel, Google Sheets, CSV, база данных.
3. Возможность запуска по расписанию (например, обновление цен каждый день) с уведомлением в Telegram.
4. Инструкцию по запуску и одну бесплатную доработку в течение 14 дней.

## Типовые задачи, которые закрываются этим кодом

- Сбор цен и наличия конкурентов для мониторинга.
- Наполнение каталога: выгрузка ассортимента в Excel для загрузки в свою систему.
- Сбор контактов и объявлений с досок.
- Сбор отзывов и рейтингов товаров для аналитики.
- Регулярный сбор статистики с сохранением истории (что изменилось за неделю).
