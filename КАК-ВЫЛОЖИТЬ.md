# Портфолио — как выложить в интернет

Эта папка — готовый сайт. Здесь лежат пять проектов и ничего лишнего:
служебные файлы магазина (сервер, тесты, ключи) в публикацию не попадают.

## Что внутри

| Папка | Что это |
|---|---|
| `index.html` | Главная: карточки всех проектов |
| `ashen/` | Магазин ASHEN — витрина с каталогом, корзиной, кабинетом и комьюнити |
| `game/` | Игра «Мини-ГТА» — аркада на canvas |
| `cases/` | Три разбора Python-проектов + архивы с кодом |

## Шаг 1. Посмотреть локально

```bash
cd ~/Desktop/проекты/portfolio-site
python3 -m http.server 8000
```

Открыть **http://127.0.0.1:8000**

Шаг необязательный, но полезно убедиться, что всё на месте.

---

## Шаг 2. Создать репозиторий на GitHub

1. Зарегистрироваться или войти: **https://github.com**
2. Нажать **New repository** — https://github.com/new
3. Имя: `portfolio` — или любое другое
4. Видимость: **Public** (для бесплатного хостинга обязательно)
5. **Не** ставить галочки «Add README» и «Add .gitignore» — они уже есть
6. Нажать **Create repository**

GitHub покажет адрес вида:

```
https://github.com/ТВОЙ-ЛОГИН/portfolio.git
```

---

## Шаг 3. Загрузить сайт

Замени `ТВОЙ-ЛОГИН` на свой логин:

```bash
cd ~/Desktop/проекты/portfolio-site
git remote add origin https://github.com/ТВОЙ-ЛОГИН/portfolio.git
git push -u origin main
```

Git попросит логин и пароль. **Пароль от GitHub не подойдёт** — нужен токен:

1. Открыть https://github.com/settings/tokens
2. **Generate new token → classic**
3. Отметить галочку `repo`
4. Скопировать токен и вставить вместо пароля

Логин при этом вводится обычный.

---

## Шаг 4. Включить сайт

В репозитории: **Settings → Pages**

- Source: **Deploy from a branch**
- Branch: **main**, папка **/ (root)**
- **Save**

Через минуту-две сайт будет доступен по адресу:

```
https://ТВОЙ-ЛОГИН.github.io/portfolio/
```

Эту ссылку можно отправлять кому угодно — откроется на любом устройстве.

## Если что-то не работает

**Страница белая или без стилей.** Проверь адрес: нужен слэш на конце —
`.../portfolio/`, а не `.../portfolio`.

**Сайт не появился через 5 минут.** Settings → Pages должен показать зелёную
плашку с адресом. Если там «Your site is ready to be deployed» — подожди ещё,
первая сборка иногда занимает до десяти минут.

**После изменений сайт не обновился.** GitHub Pages кэширует страницы.
Открой в режиме инкогнито или нажми Cmd+Shift+R.

**Хочу пересобрать после правок в проектах.** Из папки магазина:

```bash
cd ~/Desktop/проекты/интернет-магазин-ashen
node tools/build-portfolio.mjs
cd ~/Desktop/проекты/portfolio-site
git add -A && git commit -m "обновил портфолио" && git push
```

## Про оплату в магазине

На GitHub Pages магазин работает **в демонстрационном режиме**: каталог,
корзина, кабинет, комьюнити, таймеры и очередь — всё живое, а платёж создать
нельзя.

Сделано так намеренно. Платёж создаётся на сервере, потому что секретный ключ
платёжной системы нельзя держать в браузере — его увидит любой, кто откроет
исходники. GitHub Pages отдаёт только статические файлы, серверной части там
нет.

Чтобы пройти оплату целиком, магазин запускают локально:

```bash
cd ~/Desktop/проекты/интернет-магазин-ashen
node server/server.mjs
```

и открывают http://127.0.0.1:4173 — там работает весь цикл: платёж, вебхук,
чек, возврат. Подробности в `docs/payments.md` внутри проекта магазина.

Если нужна оплата на публичном адресе — понадобится хостинг с поддержкой Node
(Render, Railway, VPS) и домен с HTTPS. Это отдельный шаг, не связанный с
портфолио.
